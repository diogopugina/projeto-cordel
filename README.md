📜 Projeto Cordel
Projeto desenvolvido durante meus estudos de Desenvolvimento Web, com foco na prática de HTML5 e CSS3.

📌 Sobre o projeto
O Projeto Cordel apresenta uma página web com trechos de literatura de cordel, utilizando imagens de fundo e efeitos visuais para proporcionar uma experiência de leitura diferenciada.

🛠️ Tecnologias utilizadas
HTML5
CSS3

🎯 Objetivo
Praticar conceitos de desenvolvimento web, trabalhando com:

Estruturação de páginas HTML.
Estilização com CSS.
Imagens de fundo.
Efeito parallax.
Responsividade e apresentação visual.
